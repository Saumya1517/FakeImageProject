Methodology & Dataset

Benchmarks were evaluated using the script calculate_parameter.py across the held-out testing partition containing exactly 50 images (25 original real and 25 screen-retaken fakes).

To represent real-world use, the benchmarking includes loading images, executing local binary patterns (LBP) and gray-level co-occurrence matrix (GLCM) feature extractors at 512x512, fine-tuned ResNet18 forward passes, scaling operations, and support vector machine classification.
